# Security

This tap installs software on your machine, so a change here matters.

- Only the repository owner can push. Every cask and formula pins a sha256.
- Report a suspected problem privately through this repository's "Report a
  vulnerability" button (Security tab), not in a public issue.
- To check a download yourself, compare its sha256 with the one in the cask
  and with `manifest.json` on the matching release of
  <https://github.com/eginez/clouddeck/releases>.
